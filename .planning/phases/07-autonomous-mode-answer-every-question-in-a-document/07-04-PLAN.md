The second entry point, and everything that makes a run controllable.

"Besvar markeringen" becomes the same machine at a smaller scope. A marking with one
question and a marking with twenty behave identically — the operator raised the ten-
question case explicitly, and it is the normal case, not an edge case. Clicking it now

the operator accepted "answer everything, mark nothing in the document" only with the
gaps visible somewhere.

messages.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-15 | Denial of Service | A run the user cannot stop | mitigate | Pause is checked between answers as well as inside a session; Stop abandons the queue; both are reachable from the sticky run bar at all times while `autoRun` is non-null. |
| T-07-16 | Repudiation | Fabricated answers indistinguishable from sourced ones | mitigate | `grounded: false` answers are listed under "Uden grundlag i dine kilder" in the panel with a plain sentence saying they were answered anyway and nothing was marked in the document. This is the mitigation the operator chose inside their accepted risk, not a reopening of it. |
| T-07-17 | Tampering | Undo removing text the user wrote | mitigate | Undo delegates to each session's `undoAll`, which re-verifies its own span and refuses rather than deleting when the content moved — `PlainAdapter.undoAll` and `ContentEditableAdapter.verifyIntact` already enforce this. Failures are reported per answer. |
| T-07-18 | Information Disclosure | Selection content routed to the model | mitigate | Same server-side `contentClass: 'real'` route as the whole-document scope; no client-side switch exists. |
| T-07-SC | Tampering | npm/pip/cargo installs | mitigate | No package-manager install occurs in this plan. |
</threat_model>
